# All Steel Solutions

Código e arquivos públicos do site institucional da All Steel Solutions.

**Acesso ao site:** [all-steel-solutions.henrique-oliveira-se.chatgpt.site](https://all-steel-solutions.henrique-oliveira-se.chatgpt.site/)

O site é estático. Para mudanças futuras, edite `index.html`, `styles.css`, `script.js` e os arquivos em `assets/`. As fotos publicadas já contêm a marca d’água da All Steel. O script em `tools/watermark_images.py` serve para marcar novas fotos antes de publicá-las.

Este repositório é disponibilizado para visualização e manutenção do site. Não há licença de reutilização da logo, das imagens ou da identidade visual.
